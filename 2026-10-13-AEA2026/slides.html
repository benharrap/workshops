Packages

A package is a collection of functions usually written around a particular goal or task.

To install a package, use the install.packages function

install.packages("tidyverse")

You then have to load the package using library()

library(tidyverse)

Tip

Once you install a package it’s available for any project, no need to install for every project.

The tidyverse

A set of user-friendly tools for data manipulation and analysis

  • Reading in data (readr, readxl, haven, googlesheets4)
  • Data cleaning and manipulation (dplyr, tidyr, tibble)
  • Data visualisation (ggplot2)
  • Working with specific data types:
    • Strings (stringr)
    • Dates (lubridate)
    • Factors (forcats)

Tip

See https://tidyverse.org/packages/ for details on what’s included in the tidyverse

Package conflicts

When you load packages that have the same function name, only one will take precedence

library(MASS)

Attaching package: 'MASS'
The following object is masked from 'package:dplyr':

    select

Prevent hours of debugging by being declarative!

  • Inline solution
  • Package solution

One option is to use two colons :: to declare the package as well as the function

data |> 
  dplyr::select()

The other option is to use the conflicted package and declare preferences upfront

library(conflicted)
conflicts_prefer(
  dplyr::select,
  dplyr::filter
  )

Accessing elements of an object

Sometimes we need to access one element of an object, such as a single column in our data

We can do this using $ or [""]

data$species

data["species"]

This is not always required, such as in the context of pipes

Pipes (|>)

Chain sequences of functions together using pipes

data <- read_csv("data/penguins.csv")
data <- filter(data, species == "Chinstrap")
data <- mutate(data,
               body_mass_kg = body_mass/1000)
summarise(data, mean_body_mass = mean(body_mass_kg))

Pipes effectively fill in the first argument of a function:

data <- read_csv("data/penguins.csv")
data |>
  filter(species == "Chinstrap") |>
  mutate(body_mass_kg = body_mass/1000) |>
  summarise(mean_body_mass = mean(body_mass_kg))

Tip

The shortcut for the pipe operator is Ctrl + Shift + M

Missing

Missing has its own special identity in R — NA

penguin_species <- c("Adelie", "Gentoo", "Chinstrap", NA)
penguin_species
[1] "Adelie"    "Gentoo"    "Chinstrap" NA

It also has its own special function to check if something is missing:

is.na(penguin_species)
[1] FALSE FALSE FALSE  TRUE

Be sure to use is.na(), if you just use the equals operator it won’t work:

penguin_species == NA
[1] NA NA NA NA

dplyr::summarise()

The summarise() function applies the specified summary to the whole dataset

data |> 
  summarise(
    number_penguins = n(),
    mean_body_mass = mean(body_mass, na.rm = TRUE),
    .by = c(species, sex)
  )

ggplot2

There are many plot types available, including:

Raw data

  • Scatter plots (geom_point())
  • Dot plots (geom_dotplot())
  • Line graph (geom_line())

Summaries

  • Bar plots (geom_bar(), geom_col())
  • Bars with errors (geom_errorbar())
  • Box and whisker plots (geom_boxplot())

Distributions

  • Histogram (geom_hist())
  • Density (geom_density())
  • Violin (geom_violin())

Tip

See the documentation for all available plots https://ggplot2.tidyverse.org/reference/index.html

Modifying

Update an existing column or make a new one using mutate()

  • One variable
  • Multiple variables
  • if_else
  • case_when
  • Example
messy_data |> 
  mutate(
    var_1 = "1"
  )
  • Single equals = to specify what the variable (var_1) should be
messy_data |> 
  mutate(
    var_1 = "1",
    var_2 = 2,
    var_3 = as.numeric(var_1) + var_2
  )
  • Separate variables using commas
  • Creating a variable on an earlier line means you can refer to it within the same mutate()
messy_data |> 
  mutate(
    var_1 = if_else(
      condition = age %in% c("18", "19", "20"),
      true = 1,
      false = 0,
      missing = 0
    )
  )
  • missing specifies what to do if the value is NA
messy_data |> 
  mutate(
    age = as.numeric(age),
    var_1 = case_when(
      age %in% c(18, 19, 20) ~ "18 to 20",
      between(age, 21, 30) ~ "21 to 30",
      between(age, 30, 40) ~ "30 to 40",
      .default = "Other"
    )
  )
  • the condition (left-side) must evaluate to TRUE or FALSE
  • the value to assign if this condition is true (right-side)
  • separated by a tilde ~
  • the .default is NA if you don’t specify anything
  • applies conditions from top to bottom
messy_data <- messy_data |> 
  mutate(
    sex = case_when(
      age == "Males" ~ age,
      age == "Females" ~ age,
      .default = NA
    ),
    age = as.numeric(age),
    age_group = case_when(
      between(age, 18, 24) ~ "18 to 24",
      between(age, 25, 40) ~ "25 to 40"
    )
  )
  • sex is extracted from the age variable
  • age is numeric now
  • age_group is based on age ranges

Grouping

Use group_by() or the .by = argument

  • group_by()
  • .by =
messy_data |> 
  group_by(age_group) |> 
  summarise(
    n_total = sum(Males) + sum(Females)
  ) |> 
  ungroup()
# A tibble: 2 × 2
  age_group n_total
  <chr>       <dbl>
1 18 to 24   464094
2 25 to 40   772088
  • When you use group_by(), the output remains grouped.
  • Use ungroup() to remove the grouping
messy_data |> 
  summarise(
    n_total = sum(Males) + sum(Females),
    .by = age_group
  )
# A tibble: 2 × 2
  age_group n_total
  <chr>       <dbl>
1 18 to 24   464094
2 25 to 40   772088
  • .by applies the grouping just for that operation, so grouping doesn’t persist
  • Available for:
    • filter() and filter_out()
    • mutate()
    • summarise()
    • slice() functions
